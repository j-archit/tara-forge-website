Check the website preview first. This action commits only managed content and its referenced new photos, then pushes to origin/main.

    Open website preview ↗
    
  
    From studio to website
    1. Edit and save
      Save each collection you changed. Unsaved drafts cannot be published.
    2. Check your preview
      The launcher starts the actual website preview. Open it and check your saved changes on desktop and mobile.
    3. Publish
      On main, select Publish, optionally inspect the text diff, then commit and push from this editor. Only managed content and referenced new photos are included. GitHub Pages deploys after its checks pass.
    Uploads create local image files immediately. Removing a photo keeps its file. Hidden content and committed images are not confidential.
